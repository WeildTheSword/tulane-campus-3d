# Photo attribution

Reference photographs under `data/photos/` are redistributed here under the Creative Commons licences below.
Each image has a sidecar JSON carrying its source, author, licence and original URL; this file is generated from those sidecars.

They are used as measurement input for the facade specs in `data/facades/` (see `Docs/facade-method.md`). The specs record
measurements — colours, widths, storey heights — which are factual observations rather than derivative works of the photographs.

For the Mapillary images, Mapillary's terms ask that the Mapillary logo and a link accompany the image if you display it;
we use them only as measurement input and do not serve them.
